# HadesReality ContentOps

This is the AI-assisted Social Media Content & Publishing Platform for HadesReality.

## Folder Structure
* `apps/web`: The Next.js frontend dashboard (for human review and approval).
* `apps/api`: The FastAPI Python backend (handles business rules, AI connection, and state).
* `docker-compose.yml`: Local infrastructure setup (PostgreSQL database and n8n orchestration).

## Getting Started
Run `docker-compose up -d` to start the database and n8n locally.
